## Санаа

Энэ портфолио ердийн нүүр хуудас биш, **3D мөрдөн байцаалтын өрөө** юм. Зочин мөрдөгчийн дүрд орж, «Ганбатын Энхбаясгалан» гэдэг хэргийн хүний тухай баримтуудыг судалж, хавтас бүрийн оньсогыг бодож намайг таньж мэднэ.

- **Интро.** Харанхуй өрөөнд ард тань хаалга онгойж, коридорын гэрэл ханан дээр тусна. Малгай, урт цувтай мөрдөгчийн сүүдэр самбар дээр бууна (хүн өөрөө харагдахгүй, зөвхөн сүүдэр нь). Дараа нь ширээний чийдэн асна.
- **Корк самбар.** Хана дээрх хоёр самбарт баримт, зураг, наалтан тэмдэглэл, Монголын рельеф газрын зураг наасан. Улаан утаснууд төсөл болон ур чадварыг холбож, утас бүр яагаад холбогдсоноо тайлбарладаг.
- **4 хэргийн хавтас:** Миний тухай · Ур чадвар · Бүтээлүүд · Амжилт ба нийгмийн оролцоо. Хавтас бүр жижиг оньсоготой (код, шифр, холболт, тааруулах), хүсвэл алгасаж болно. Оньсогыг бодоход «НЭЭГДСЭН» тамга дарагдаж, хавтас нээгдэнэ. Дотор нь үнэмлэх, хэргийн тайлан (үндсэн мэдээлэл, ур чадварын түвшин, бүтээлүүд, амжилт) ба байцаалтын тэмдэглэл бий.
- **Заавар.** Анх ороход хэн бэ (нэр, чиглэл, зорилго), юун дээр дарж юу харах вэ гэдгийг 4 алхмаар тайлбарласан заавар гарна. Дараа нь **?** товчоор дахин нээнэ.
- **Бүтээлүүдийн carousel (▦).** Бүтээл бүрийг зураг, тайлбар, технологи, сайт/GitHub линктэй нь гүйлгэж үзнэ (сум, цэг, хуруугаар гүйлгэх, ← → товч).
- **Ур чадварын түвшин.** Ур чадвар бүрийг өөрийн үнэлгээний %-иар progress bar-аар харуулна.
- **CV татах (↓).** Албан CV-г PDF-ээр шууд татна.
- **Монгол / English.** **EN / MN** товчоор бүх сайт (3D баримтууд, хавтас, оньсого, заавар) хэл солигдоно.
- **CRT зурагт ба 2 кассет.** 1-р кассетэнд миний тухай гэрийн бичлэг маягийн видео, 2-р кассетэнд хөгжим бий. Кассетыг тоглуулагч руу хийхэд хуучин зурагт асна.
- **Томруулдаг шил (M).** Хулганыг дагаж, өрөөг 2.6 дахин томруулж харуулна. Нэг цаасны доор далд тэмдэглэл нуугдсан байгаа.
- **Төгсгөл.** Бүх хавтсыг нээсний дараа «Хэргийг хаах» товч гарна. Өрөөнөөс гарч хаалга хаагдахад «ХЭРЭГ ХААГДСАН» тамга дарагдаж, CASE CLOSED тайлан гарна.

Session бүрт баримтын байрлал, оньсогын утга seeded random-оор өөрчлөгддөг. Харин хариутай нь хамт үүсдэг тул оньсого үргэлж бодогдоно.

## Технологи

- **HTML, CSS, JavaScript (ES module)**. Framework, build алхам байхгүй.
- **three.js r170** (`vendor/` дотор, CDN хэрэггүй), GLTFLoader.
- **WebGL:** PBR материал, SpotLight + PCF soft сүүдэр, хаалганы хэлбэртэй гэрлийн «gobo», render target (томруулдаг шил), Raycaster (дарсан объектыг олох).
- **Canvas 2D:** баримт бүрийн гадаргууг `content.js`-ийн өгөгдлөөр бодит цаасны бүтэц дээр зурна.
- **Web Audio:** дууны эффектүүд. Файл ачаалагдаагүй үед богино синтезээр орлуулна.
- **sessionStorage / localStorage:** явц, баримтын байрлал, дууны тохиргоо.

## Локал дээр ажиллуулах

ES module ашигладаг тул файлыг **http-ээр** нээх хэрэгтэй. VS Code дээр `index.html` → **Open with Live Server**. Файлыг шууд давхар товшиж нээвэл 3D ажиллахгүй, зөвхөн жагсаалт харагдана.

## Байршуулалт

Vercel: **Framework Preset: Other**, Build Command болон Output Directory хоосон. Статик сайт тул npm, build шаардлагагүй. `main` салбар руу push хийх бүрт автоматаар дахин байршина.
